My top choice:

NeuroLearn AI Smart Emotion-Based Learning Platform web application using React 18, Tailwind CSS, React Router v6, and Recharts. The app uses webcam-based emotion detection to adapt learning content in real time. The UI must be modern, dark-themed, professional, and production-grade.

Design System

•	Theme: Dark mode primary — deep navy/dark blue backgrounds (#0F0F1A, #1A1A2E)

•	Accent Color: Electric blue (#4F8EF7) for CTAs, highlights, active states

•	Secondary Accent: Soft purple (#7B5EA7) for badges, tags, emotion indicators

•	Font: Use 'Inter' from Google Fonts — clean, modern, readable

•	Cards: Glassmorphism style — semi-transparent with blur backdrop, subtle border

•	Buttons: Rounded pill style with gradient hover effects

•	Animations: Smooth fade-in on page load, subtle hover scale on cards

•	Icons: Use lucide-react icon library throughout

Routing Structure

/login → Login

State Management

•	Use React Context API for: AuthContext (user, role, login, logout)

•	Use local useState/useEffect for page-level state

•	No Redux needed

Important Notes for Lovable

•	Do NOT connect Firebase yet — use mock data and local state only

•	All forms should have controlled inputs with useState

•	No HTML <form> tags — use div with onClick handlers

•	Make all pages fully responsive (mobile, tablet, desktop)

•	Add smooth page transitions using CSS opacity/transform animations

•	Every interactive element must have hover and active states

•	Use Tailwind classes exclusively — no inline styles
